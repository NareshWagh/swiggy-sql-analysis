# 🍔 Swiggy Restaurant Data Analysis (SQL Project)

## 📌 Project Overview
An end-to-end data analysis project exploring 1.4 lakh restaurants listed on Swiggy across 600+ Indian cities using **SQL**. The objective was to clean raw data and uncover business insights regarding popular cuisines, city ratings, restaurant chains, and pricing patterns.

> **Resume Highlight:**  
> *"Analysed 150,000+ Swiggy restaurant records across 600 Indian cities using SQL — identified top cuisines, pricing patterns, and city-wise performance trends."*

---

## 📊 Dataset Source
* **Dataset Name:** Swiggy Restaurants Dataset
* **Source:** [Kaggle Dataset](https://www.kaggle.com/datasets/ashishjangra27/swiggy-restaurants-dataset)
* **Columns:** `restaurant_name` | `city` | `cuisine` | `rating` | `rating_count` | `cost` | `lic_no` | `link`

---

## 🛠️ Tech Stack & Skills Demonstrated
* **Database/Tool:** PostgreSQL / DB Browser for SQLite
* **SQL Skills:** Data Cleaning, Aggregations, `GROUP BY`, `HAVING`, Filters, String Manipulations.

---

## 🚀 How to Run This Project
1. Clone or download this repository.
2. Load your `swiggy.csv` dataset into your database.
3. Run `queries/data_cleaning.sql` followed by `queries/analysis.sql`.
